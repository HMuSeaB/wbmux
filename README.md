# wbmux

**WorkBuddy (CodeBuddy) 国内版 / 国际版多环境协同、模型网关与会话管理工具。**

让国内版与国际版客户端无缝协同：无需额外安装国际版桌面端，通过官方标准 Web 授权接入国际端特惠模型资源，并平滑桥接至本地客户端；同时提供多账号环境隔离、会话迁移与统一资产监控大屏。

---

## 🌟 核心特性

- ⚡ **官方原生 Web 授权桥接 (Official Web Auth Flow)**：
  完整实现官方标准 Client 授权协商协议，点击即可唤起浏览器官方正规登录页完成身份核验，由本地回环自动接收凭证，彻底摆脱繁琐的手动提取与配置。
- 🤖 **国际大模型按需自选与国内客户端桥接 (Selective Model Ingestion)**：
  打破单一免费限制，支持在模型库中一键自选高级付费大模型（如 GPT、Grok、Kimi 等）快捷桥接至国内客户端下拉菜单；清晰透明标注官方消耗倍率（如 `2.00x`、`1.50x`），并配备毫秒级即时搜索与多维度分类筛选器。
- 🔄 **多账号智能故障转移与高可用保障 (Auto-Failover Resilience)**：
  账户池智能协同，当主力账户遭遇临时配额限制或频控时，网关透明秒级轮转至备用健康账号无感重试，保障长链路 Agent 任务不中断。
- 👥 **多账号与工作空间隔离 (Multi-Account Vault)**：
  支持同时管理多个独立账户（如个人开发账号、团队专属账号），提供配置与会话的安全隔离存储，并在资产大屏上一键平滑切换当前活跃身份。
- ⏳ **授权凭证长效自动无感保鲜 (Token Auto-Refresh)**：
  完整支持官方长效凭据续期规范，后台自适应守护巡检与临期静默更新，彻底解决登录态频繁过期的繁琐痛点。
- 🛡️ **客户端协议同构与会话守护 (Telemetry Guardian)**：
  严格同构官方桌面客户端的标准通信协议规范与设备环境标识，内置自适应心跳保鲜与智能节流算法，杜绝机械请求与网络风暴，保障本地长连接的高稳定性。
- 📊 **三联 KPI 资产透视看板与成长激励联动**：
  国内版额度状态、国际版可用余量、模型特惠周期置顶整合；站内原生透视积分包到期与扣减顺序，打通官方阶段活跃激励就地兑换。
- 🚀 **全终端与移动生态无缝兼容**：
  本地桥接模式下仅需运行国内客户端，所有对话请求透明转发，**移动端（微信小程序 / 企业微信移动办公）远程协同不受任何影响**。

## 💡 使用姿势选型

| 使用姿势 | 适用场景 | 核心优势 |
|---|---|---|
| **🌟 协同网关模式（日常最推荐）** | 仅使用国内客户端，但需调用国际端开放模型 | **免装国际版桌面端**，一键接入国际模型，请求走本机代理转发，**小程序/移动协同 100% 正常** |
| **👥 多账号轮换** | 拥有多个账户（个人学习、企业办公、测试账号） | 内置账号保险库，界面一键平滑切换当前活跃身份，自动热重载本地凭据与状态监控 |
| **🚀 双端独立运行** | 同时需要两端原生桌面客户端及各自专属功能 | 一键启动两个客户端，国内端管微信/企微生态，国际端管专属渠道，**配置与环境完全隔离** |
| **🔄 启动/切换模式** | 一份安装按指定后端参数启动 (`wbmux run cn/intl`) | 动态加载环境配置变量，适用于特定自动化测试脚本与流水线调试 |

> 📌 **原理解惑**：如果你平时主要依靠**将国际端模型桥接至本地客户端**，你正在使用的是最稳健的**协同网关模式**！你完全不需要下载安装国际版客户端安装包，也无需运行 `wbmux run intl`。

## 🚀 快速上手

从 [Releases](../../releases/latest) 下载对应系统架构的发布包解压，或通过源码编译运行：

```bash
# 1. 启动图形管理大屏（双击 wbmux.exe 效果相同）
wbmux gui

# 2. 检查本机环境与配置文件完整度
wbmux doctor

# 3. 查看本机探测到的客户端安装与版本信息
wbmux list
```

---

## 🛠️ 常用命令速查

```bash
# 界面与服务
wbmux gui                  # 启动本地现代化管理大屏（默认监听 127.0.0.1 安全端口）
wbmux doctor               # 执行本地环境与配置自检

# 客户端运行
wbmux run intl --dry-run   # 预览将要加载的配置与启动参数（不实际启动进程）
wbmux run cn               # 按国内环境启动客户端
wbmux run intl             # 按国际环境启动客户端

# 会话与工具
wbmux checkin claim        # 执行今日打卡同步
wbmux migrate              # 列出两端可相互迁移的会话与历史（只读检查）
wbmux sessions             # 跨 IDE 会话中心（按项目归组浏览，支持 --web）
```
