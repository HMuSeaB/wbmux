# wbmux 使用说明

## 先选对用法（三选一）

| 你想要什么 | 用哪种 | 状态 |
|---|---|---|
| **同时**用国内+国际（推荐） | 目标后端区块的 **🚀 双开两侧** | ✅ 可用 |
| 一个壳子连国际后端 | 切换 + 启动客户端 | ❌ 5.6.2 宿主实测会**静默回落国内**（见下） |
| 排错对照 | 勾选原生模式再启动 | ✅ 可用 |

## 双开（推荐用法）

点「🚀 双开两侧」，两个客户端同时启动、各用各的账号：

- **国内客户端（WorkBuddy）**：小程序远程控制、国内模型、**国内额度**
- **国际客户端（WorkBuddy AI）**：国际模型、**国际额度**
- **想不花钱**：国际客户端里用这三个**限时免费**模型（0.00x，到 10 月上旬）：
  **DeepSeek-V4.1-Flash、Hy4 preview、Hy3**

额度跟账号走：国内额度只在国内客户端扣，国际额度只在国际客户端扣，互不相通。

## 切换模式为什么现在别用

2026-09-26 四组对照实验（含会话交换：国际会话写入国内认证文件，仍连国内后端——环境域名表来自客户端捆绑配置，国内 exe 域名表没有 workbuddy.ai）（本机、无干扰）：国内 5.6.2 宿主挂上国际配置后，
客户端仍按**登录会话**解析产品环境，静默回落国内——界面显示"已选国际"，
实际连的还是国内后端、扣的还是国内额度。这不是操作问题，是客户端 5.6
的会话推导机制压过了配置覆盖（详见 commit 43fba9d 的实验记录）。
要恢复单壳切换，需要做"认证文件会话切换"，待定。

## 怎么分清当前窗口是哪一侧

- 任务栏/窗口标题：**WorkBuddy** = 国内；**WorkBuddy AI** = 国际
- 模型选择器：有 **Primary / 极致 / GPT-6-Astra** = 国际；有 **夜间折扣** 标签 = 国内
- wbmux 面板瓷砖：显示账号（国际=昵称，国内=UID 前缀）

## 提供方：用你自己的 key（BYOK）

侧边栏「提供方」页。填一张卡片 = `名字 + 完整的 chat/completions 地址 + API Key
+ 模型名清单`，保存后立刻注入国内客户端，模型选择器里出现「卡片名 · 模型名」。

- 请求仍然走本机代理，但**用的是你填的 key**，不借任何 WorkBuddy 账号——
  所以国际客户端装不装、登没登录都无所谓
- 上游 key 只写在 `%USERPROFILE%\.wbmux\config.json`（0600）；注入到客户端
  目录的条目持有的是本机代理的令牌，**上游 key 不会进客户端数据目录**。
  界面上也只回显 key 的最后 4 位，留空表示不改动
- 代理按条目前缀分流：`wbmux-intl-*` 走国际后端，`wbmux-byok-<卡片 id>-*`
  走对应卡片。所以两边的模型可以同时存在，互不影响
- 删卡片或改模型清单后，注入条目会整体重建（旧的不留残影）
- 「支持工具调用」默认勾选：取消勾选会让客户端把请求体里的 tools 删掉，
  Agent 就没法干活了

## 无缝模式：国际模型注入国内客户端（推荐）

额度面板里点「📤 注入国际模型到国内客户端」：把三个限时免费模型
塞进国内客户端的自定义模型清单。之后**只开国内客户端**，模型选择
器底部就有"XXX（国际免费）"——发消息经本机代理转国际后端、扣国际
额度（免费模型 0 积分），小程序远程控制完全不受影响。

- 注入会备份原文件（models.json.wbmux-bak）；你自己的自定义模型不动
- **地址与令牌跨重启沿用**（存在 `~/.wbmux/config.json`），所以只有第一次
  注入之后需要重启国内客户端；之后重启 wbmux 不用再重启客户端
  （端口被别的程序占用时会退回随机端口，那一次界面会提示你重启客户端）
- wbmux 每次启动仍会自动重新同步：模型清单本身会变（活动、模型上下线）
- 国内客户端里手动编辑自定义模型会覆盖注入条目，重新点一次按钮即可
- 条目里的能力开关（支持工具/图片）与上下文上限**照抄官方配置**，
  不再硬编码；代理原样透传请求体，工具调用可以正常走
- 模型名会由代理还原：客户端发来的是带 `wbmux-intl-` 前缀的条目 id，
  代理剥掉前缀再转上游（漏了这步上游会 400，客户端只显示一句「502」）
- 客户端报错时看界面侧边栏的「📡 代理日志」：每次请求的模型名、工具数、
  上游状态码、耗时与回包大小都在里面（同一份也写进 `%USERPROFILE%\.wbmux\gui.log`）。
  只有「收到请求」没有「转发完成」＝ 卡在上游还没回来
- 上下文窗口照抄官方值（DeepSeek-V4.1-Flash 1M）：**已实测 95 万 token 的
  请求能通过**（2026-09-27，流式 200）。那种请求的请求体约 11 MB，
  代理的上限是 32 MB，够用

## 一键测试

「🧪 一键测试」对两侧各发一条最小消息并对比前后账单，直接告诉你：
后端通不通、实际服务的模型、扣哪个账号多少积分。
模型自动挑限时免费/0 倍率的，基本零成本。

## 已知限制

- 国内版实时数据不可用：5.6+ 凭据是加密信封，本地解不开（面板显示安装包快照）
- 「远程控制」的微信系渠道绑定国内后端，切到国际后端会失效（双开不受影响）
- 客户端升级后内部结构可能变化，面板读数以实际为准
