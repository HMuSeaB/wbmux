提供方（自备 key）

在这里填你自己的 OpenAI 兼容端点，保存后会注入国内客户端：模型选择器里出现 「卡片名 · 模型名」。请求仍走本机代理，但这次用的是你填的 key， 不依赖任何 WorkBuddy 账号——所以国际客户端卸不卸载都无所谓。

上游 key 只写在 %USERPROFILE%\.wbmux\config.json（0600）， 不会进客户端的数据目录；界面上也只回显最后 4 位，留空表示不改动。

压缩阈值

客户端在发消息前会检查上下文占用，到阈值就把旧历史压缩掉 —— 表现是"聊到一半模型突然忘了前面说过什么"。它判断"满了没"用的 基准窗口默认只有 200k， 而你选的国际模型（deepseek-v4.1-flash、hy4-preview-f）实际窗口是 1M。 把基准调大，压缩就来得更晚，模型记得更久。

将要做的改动

历史搬运

把一侧的会话、附件、内容配置、技能与记忆搬到另一侧。两套后端的账号体系不互通、 数据目录也不同，官方没有同步途径——这是把另一侧的东西带过来的唯一办法。

会话里的图片存的是绝对路径，所以搬会话时会同时把被引用到的图片搬过来， 并把会话内的路径改写到目标端数据目录。代价是副本与原文件不再逐字节一致， 换来的是你可以放心删掉来源端数据目录。

会话工作区

客户端把"工作区"记在三处：工作区清单、每条会话的 cwd、以及正文文件所在的 projects 目录。 随手只改一处，就会出现"清单里有这个目录、点进去没有会话"，或者"会话还在、 但归到了另一个项目下"。这一页把三处一起处理。

另外，同一个目录在数据库里可能同时存在 C:/… 与 C:\… 两种写法——客户端把它们当两个项目，于是列表里出现两个入口。 下面的"合并写法"就是干这件事的。

迁移到别处

把整个工作区搬到另一个目录：文件复制过去、会话记录改指向、会话正文里 记着的绝对路径也一并改写。源目录不会删——确认没问题后你自己删。

为什么要点两下

这个操作改的是你的历史会话索引，写坏了就是"会话全消失"。 所以按钮分两步：先算一遍给你看（改多少条会话、多少个文件、哪些正文含旧路径）， 确认无误再执行。执行前会自动备份数据库。

执行时客户端必须完全退出。它握着会话列表的内存缓存， 边跑边改会被它回写覆盖——表现是"改了没生效"，或者更糟：索引与正文对不上， 列表里点开是空白。所以这一页在客户端运行时会把执行按钮锁住。

全自动化逆向原理与合规边界

为什么纯 API 就能点亮？
官方判定任务完成的通道是 POST /v2/report。经过逆向 app.asar 与抓包解密，官方不同任务严格识别特定的客户端指纹（桌面端 5.5.6 事件族、Web 域元素点击、小程序专属请求头）。 wbmux 将这些事件链原汁原味地封装为纯 API 流水，同时针对专家与技能类任务通过微秒级短会话从 SSE 流截取服务端真实会话 ID 注入回填，因此无需打开官方客户端即可完成。

计分异步落账保护：
官方服务端计分存在 3~8 秒异步延迟，wbmux 采用有界退避回读轮询，在落账后自动调用 claim 接口将积分与能量真正领到账号中，无需人工反复盯梢。

每日签到

连签会累计积分，断一天就归零。这一页读的是国内版账号—— 签到目前只在国内侧开放，国际侧接口在、活动没开。

打开 wbmux 就自动签了，不用切到这一页——先查状态， 只有今天还没签才领；已签过就只记下状态、不再重复领。 这一页是给你看结果的：今天签没签、连了几天、还剩多少。

自动签到的边界

自动签到会改账号状态（领积分、改连签天数），是 wbmux 里少数几个 会写远端的地方，所以它的行为被限制得很死：

只在「今天还没签」时才领。已签过、没开活动、或者状态根本查不到 （没登录 / 断网），都一个请求都不发——宁可什么都不做，也不在 看不清状态的时候乱改账号。判断放在服务端做，不靠页面自己算。

每天会自己刷新。「今天签了没」由后端按自然日判定，跨过午夜就 自动变成"没签"，第二天打开界面会重新领——不需要你做任何事，也不需要 wbmux 常驻后台。

不想要自动的，把上面的勾去掉。关掉之后连一次查询都不会发。 想在固定时刻领（比如每天 9 点），用命令行 wbmux checkin claim 交给系统任务计划程序，它同样是幂等的：签过就如实回报，不会重复领也不会报错。

回收站清理

按能不能放心删分成三档。卡死的原因是条目数而不是体积—— 资源管理器要逐个读元数据才能画出列表，几千条就转不动了。 每档都能单独清，越往下越危险；自动清理只碰第一档。

自动清理

开启后每 30 分钟自动清一次已识别的噪声，绝不碰你自己删的文件。 开关会记住，下次打开界面仍然有效。
注意：wbmux 进程不开着的时候它不会运行——关掉界面就等于停了。 想让它常驻，把 wbmux 留着别关。
