# wbmux

**WorkBuddy 国内版 / 国际版多功能复用与模型转发器。**

让国内版与国际版共存协作：既支持一键将国际免费模型注入国内客户端（保留小程序与企微远程控制），也支持双开管理与配置复用。

---

## 💡 先选用法（哪种适合你？）

| 使用姿势 | 适用场景 | 核心优势 |
|---|---|---|
| **🌟 无缝模式（日常最推荐）** | 平时只开国内版，但想白嫖国际免费模型 | 打开 WebUI 一键注入自定义模型，请求走本机代理转国际后端，**小程序/企微远程控制 100% 正常** |
| **🚀 双开两侧** | 同时需要国内和国际原生界面及各自专属功能 | 一键启动两个客户端，国内管微信/企微生态，国际管海外账号与专属渠道，**配置与额度完全隔离** |
| **🔄 启动/切换模式** | 一份程序按指定后端启动 (`wbmux run cn/intl`) | 动态注入 `ACC_PRODUCT_CONFIG_PATH` 环境变量（*注：5.6.2+ 会因会话校验优先回落，详见下文*） |

> 📌 **原理解惑**：如果你平时靠的是**国际版转发并注入到国内版自定义模型**，你正在使用的是最稳健的**无缝模式**！你完全不需要运行 `wbmux run intl` 来给主程序换壳。

## 🚀 快速上手

从 [Releases](../../releases/latest) 下载对应系统解压，或通过源码编译：

```bash
# 1. 启动图形管理面板（双击 wbmux.exe 效果相同）
wbmux gui

# 2. 检查本机安装与配置环境健康度
wbmux doctor

# 3. 列出本机探测到的安装路径与版本
wbmux list
```

---

## 🛠️ 常用命令速查

```bash
# 界面与服务
wbmux gui                  # 启动本地管理页面（默认 127.0.0.1）
wbmux doctor               # 执行环境与配置体检

# 客户端运行
wbmux run intl --dry-run   # 预览将要改写的配置与启动命令（不实际启动）
wbmux run cn               # 按国内配置启动
wbmux run intl             # 按国际配置启动

# 会话与历史
wbmux migrate              # 列出两端可相互搬运的会话与历史（只读）
wbmux sessions             # 跨 IDE 会话中心（按项目归组浏览，支持 --web）
wbmux checkin claim        # 自动执行今日签到领取积分
```
