# wbmux

**WorkBuddy 国内版 / 国际版多功能复用、模型转发器与账号资产管家。**

让国内版（CodeBuddy）与国际版（WorkBuddy AI）无缝共存与协作：**无需下载几百兆国际客户端**，通过官方拟真协议一键登录获取凭证，将国际限免大模型（DeepSeek / Hy4 等 0.00x 费率模型）无感注入国内客户端；支持多账号随时平滑切换、反风控遥测心跳守护与全景资产大屏。

---

## 🌟 核心功能亮点

- ⚡ **官方拟真一键登录（免抓包 · 免开 F12 · 免装客户端）**：
  基于官方原生认证协议同构还原，点击按钮即可自动唤起浏览器完成官方正规登录，后台安全捕获 AccessToken 与长效 RefreshToken 并自动入库激活，告别繁琐的手动复制。
- 👥 **国际版多账号管理池 (Multi-Account Vault)**：
  支持同时纳管大号、备用号与活动积分号，资产大屏随心随时一键切换当前活跃账号，配置与会话无感热更新。
- 🛡️ **反风控遥测与心跳守护体系 (Telemetry Guardian)**：
  生成并持久化唯一设备硬件指纹（`~/.wbmux/device.id`），全链路模拟官方真实 Electron 桌面端完整 UA；后台自适应随机抖动心跳保鲜，移除高频机械轮询，彻底规避风控检测。
- 📊 **三联 KPI 资产透视总览看板**：
  国内可用积分与连签态、海外可用积分包余量比、0.00x 限免模型矩阵与到期倒计时置顶呈现；支持就地一键打卡与开机自动静默打卡领积分。
- 🚀 **无缝注入模式（最强日常推荐）**：
  平时仅需运行国内客户端，所有对话请求经由 wbmux 本机代理转发至国际后端，**微信小程序 / 企业微信远程控制 100% 正常可用**！

## 💡 使用姿势选型

| 使用姿势 | 适用场景 | 核心优势 |
|---|---|---|
| **🌟 无缝模式（日常最推荐）** | 平时只开国内版，但想白嫖国际免费大模型 | **免装国际客户端**，一键注入自定义模型，请求走本机代理转国际后端，**小程序/企微远程控制 100% 正常** |
| **👥 多账号轮换** | 拥有多个国际账号（主力号、备用号、活动小号） | 内置账号保险库，界面一键平滑切换当前活跃身份，自动热重载官方凭据与用量监控 |
| **🚀 双开两侧** | 同时需要国内和国际原生界面及各自专属功能 | 一键启动两个客户端，国内管微信/企微生态，国际管海外账号与专属渠道，**配置与额度完全隔离** |
| **🔄 启动/切换模式** | 一份程序按指定后端启动 (`wbmux run cn/intl`) | 动态注入 `ACC_PRODUCT_CONFIG_PATH` 环境变量（*注：5.6.2+ 会因会话校验优先回落，详见下文*） |

> 📌 **原理解惑**：如果你平时靠的是**国际版转发并注入到国内版自定义模型**，你正在使用的是最稳健的**无缝模式**！你完全不需要下载安装国际版客户端，也不需要运行 `wbmux run intl` 来给主程序换壳。

## 🚀 快速上手

从 [Releases](../../releases/latest) 下载对应系统解压，或通过源码直接运行：

```bash
# 1. 启动图形管理大屏（双击 wbmux.exe 效果相同）
wbmux gui

# 2. 检查本机安装与配置环境健康度
wbmux doctor

# 3. 列出本机探测到的安装路径与版本
wbmux list
```

---

## 🛠️ 常用命令速查

```bash
# 界面与服务
wbmux gui                  # 启动本地现代化管理大屏（默认 127.0.0.1 随机安全端口）
wbmux doctor               # 执行环境与配置健康体检

# 客户端运行
wbmux run intl --dry-run   # 预览将要改写的配置与启动命令（不实际启动）
wbmux run cn               # 按国内配置启动客户端
wbmux run intl             # 按国际配置启动客户端

# 会话与资产
wbmux checkin claim        # 自动执行今日打卡领取积分
wbmux migrate              # 列出两端可相互搬运的会话与历史（只读）
wbmux sessions             # 跨 IDE 会话中心（按项目归组浏览，支持 --web）
```
